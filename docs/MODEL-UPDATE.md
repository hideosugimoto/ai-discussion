# AI モデルを載せ替えるときの手順

このファイルは `CLAUDE.md` から参照される。モデル更新の作業に入るときだけ読む。

単一ソースは `src/models.config.js`。価格根拠と仕様上の罠は同ファイルのコメントにある。
ここには手順と**過去に実際に踏んだ失敗**だけを置く。

1. **価格は各社の公式価格ページで一次確認する。** プロモ価格と定価の取り違えを**2回**
   踏んでいる（#7 の Gemini 3.6 Flash、2026-10 の `gpt-5.6-*` は luna が5倍の過大計上）。
   提供状況は各社 `/v1/models` の実レスポンスで確認する（実 ID に `-preview` が
   付かない＝GA の判定基準は #7 のコメント）
2. 時限価格は `until` / `after` で期日切替にする。**終了後価格が非公開なら `after` を
   書かず、その事実をコメントに残す**（安い値だけ入れると期日後に過小計上＝赤字）
3. Anthropic のキャッシュ読み出し倍率は**モデル別**（`anthropicCacheReadMultiplier`）。
   固定値にすると調査モードの計上が倍になり、有料ユーザーの上限を削る
4. `npm run sync:models` → `npm test`。表示ドリフトテストが LP・README・UI に残った
   旧モデル名を検出する。続けて `node scripts/check-models.mjs` で未登録 0 件を確認
5. **最後は実リクエストで検証する。** 価格表とビルドが通っても、モデル側の仕様変更で
   壊れる。SSE ストリーミング経路（本文抽出と usage 抽出の両方）と
   `functions/api/trial/chat.js` の非ストリーミング経路の両方を叩く。2026-10 の
   Claude 5.5 移行では、thinking を無効化できない仕様（`output_config.effort` が唯一の
   レバー）のため、**LP の無料トライアルが本文を返さなくなる不具合が実際に発生した**
   （`content[0]` が thinking ブロックになり、思考が `max_tokens` を使い切る）
